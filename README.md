En este proyecto creé un sistema para controlar el préstamo de equipos de computación, como laptops y tablets. Lo que hice fue organizar toda la información en un diccionario principal donde cada equipo guarda su estado y una lista de sus préstamos. Para que los datos no se borren o se cambien por error, cada vez que alguien pide un equipo, su nombre y la fecha se guardan en una tupla, que es un tipo de dato que no se puede modificar. El programa tiene un menú que se repite para que yo pueda ver qué hay disponible, registrar entregas, devolver equipos que estaban prestados o incluso añadir equipos nuevos al inventario, lo que me ayudó a entender mucho mejor cómo manejar listas y diccionarios en un caso real.
